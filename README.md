# 五十音手帖

中文界面的日语假名学习页，使用 HTML、CSS 和 JavaScript，无需构建。

**在线使用：https://kana.662613.xyz/**

- 平片假名共208张字卡，支持切换、对照和搜索。
- 动态笔顺、逐笔播放、PNG/GIF/SVG素材与手写练习。
- 71个真人单音：55个Fukujinzuke + 16个Tofugu。
- 拗音33组提供笔顺和图像，暂未收录音频。
- 下载仓库后直接打开 index.html，也可离线使用。
